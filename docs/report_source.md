# Report source and versions

**The final PDF is canonical.** The report is a Word document with a PDF; the publication copy is added to `report/final/` (Word and PDF) with release v1.0.0.

* `report/final/` is the publication copy and is the only part of `report/` that is published.
* The rest of `report/` (earlier versions, working copies with tracked changes, source images) is private working material and is not part of the repository.
* Every number of the report is in `docs/claims_map.csv` with its evidence label, source script and output file; `docs/claims_map_6b*_changes.csv` and `docs/claims_check_6b*.csv` record the claims changes and checks of the last editing passes.
* Figures that are scripts are in `src/06_figures/`; static pictures (for example the stage diagrams) are part of the report file.
